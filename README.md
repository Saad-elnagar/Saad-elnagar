## 👋 About Me

I'm Saad, a Computer Science student from Egypt (Class of 2026) and a freelance developer focused on **C#, ASP.NET Core, EF Core, and SQL Server**. I build backend-led applications with clear layers, practical database design, and business logic that's easier to understand and maintain.

I care about more than making a feature work: I aim to keep the scope clear, handle edge cases, protect data integrity, and leave clients with code they can continue working on.

**Best fit:** focused .NET tasks, new API features, database-backed workflows, bug fixes, and improvements to existing applications.

## 🛠️ What I Can Help With

- **ASP.NET Core development** — REST API endpoints, MVC features, CRUD workflows, and service-layer logic.
- **SQL Server & EF Core** — relational data access, LINQ queries, migrations/scaffolding, and database-backed workflows.
- **Bug fixing & maintenance** — reproduce issues, trace the cause, implement a focused fix, and validate affected behavior.
- **Architecture & refactoring** — practical separation of concerns with layered / 3-tier architecture, dependency injection, and SOLID principles where they fit the project.
- **Integrations & tooling** — work involving authentication, Redis, Stripe, Docker, and API documentation, depending on the requirements.

## 🤝 How I Work With Clients

1. **Clarify first:** agree on expected behavior, deliverables, constraints, and acceptance criteria before implementation.
2. **Keep changes understandable:** favor readable code and an architecture proportionate to the size of the task.
3. **Validate the important paths:** run relevant builds and tests, and check edge cases within the agreed scope.
4. **Communicate clearly:** share progress, flag blockers early, and include practical setup or handoff notes.

I take on work that matches my current skills and will be transparent about assumptions, risks, and scope.

## 🚀 Selected Projects

### [Talabat — E-Commerce API & Angular Storefront](https://github.com/Saad-elnagar/Talabat)

A full-stack e-commerce learning project with a layered .NET backend and a separate Angular storefront.

- Product catalog queries, filtering, pagination, basket and order workflows.
- Authentication with ASP.NET Core Identity and JWT.
- Stripe payment-intent integration and Redis-backed basket/cache infrastructure.
- Separate Domain, Application, Infrastructure, and API projects.

**Stack:** C# · .NET · ASP.NET Core Web API · EF Core · SQL Server · Redis · JWT · Stripe · Angular · Docker

### [Inventory Management System](https://github.com/Saad-elnagar/InventoryManagement)

An ASP.NET Core MVC application for day-to-day inventory workflows.

- Manages products, categories, suppliers, customers, purchases, sales, and stock movements.
- Uses a 3-tier structure to separate Web, Business Logic, and Data Access.
- Uses EF Core database-first scaffolding, repository abstractions, and Unit of Work.
- Includes low-stock monitoring, reporting, role-based access, and an optional read-only AI assistant.

**Stack:** C# · ASP.NET Core MVC · EF Core · SQL Server · Docker

### [Quantum Radar — Traffic Violation Engine](https://github.com/Saad-elnagar/Fawry.Quantum_Radar)

A C# rule-based traffic violation processor designed around separate, extensible violation rules.

- Evaluates speeding and seatbelt observations.
- Keeps individual checks separated behind an interface for easier extension.
- Combines detected violations into fine records and tracks counts by rule.

**Stack:** C# · .NET · OOP · Interfaces · Strategy-style rule separation

### [Company Management System](https://github.com/Saad-elnagar/3-Tre-MVC)

An ASP.NET Core MVC project for employee and department management.

- Implements CRUD and employee search workflows.
- Separates presentation, business logic, and data access.
- Uses EF Core, SQL Server, ViewModels, AutoMapper, and repository abstractions.

**Stack:** C# · ASP.NET Core MVC · EF Core · SQL Server · AutoMapper
